# Eduvixo Web Push 1.0.8

Status: COMPLETE. Standards-based Web Push is deployed on the Eduvixo demo and Shoudu installations as core version 1.0.8. Eduvixo Calendar 1.1.1 uses the same browser delivery channel.

## Delivered scope

- Added installation-specific P-256 VAPID key generation and protected storage. Private keys are created on the target installation, are never included in packages or Git and use mode `0600`.
- Added RFC 8291 `aes128gcm` payload encryption and RFC 8292 VAPID ES256 authorization without a new runtime dependency.
- Added encrypted-at-rest browser subscription storage. Plain endpoint capability URLs and subscription keys are not stored in database columns or logs.
- Added authenticated JSON API actions for status, subscribe, current-device revoke, all-device revoke, category preferences and test delivery. All writes require CSRF verification; demo users remain read-only.
- Added a root-scoped, no-cache Service Worker with safe same-origin click routing, notification display and resubscription signalling.
- Added an explicit consent-first settings interface. Browser permission is requested only after the user selects `Enable`; there is no automatic prompt.
- Added per-user categories for workflow/personal, chat, forms, surveys, Calendar, product updates and license/security notifications.
- Integrated Web Push with the existing notification journal and one-per-minute worker. Delivery includes audience revalidation, deduplication, expiry handling, delivery telemetry, bounded retries for unambiguous `429`/`5xx` responses and no blind retry after an indeterminate network result.
- Restricted push endpoints to HTTPS, trusted browser push-service host suffixes and public DNS addresses pinned for the request. Redirects, private/reserved targets, userinfo and non-443 ports are rejected.
- Updated the notification-channel overview with Web Push health and delivery metrics.
- Updated signed core release/catalogue metadata to 1.0.8 and Eduvixo Calendar to 1.1.1 Stable.

No existing table or column was removed. Migration `025_web_push.sql` only adds `web_push_preferences`, `web_push_subscriptions` and `web_push_deliveries`.
